# TokoFlow — Prototipe Web POS

## Cara melihat langsung
Buka `index.html` di browser. Demo kasir bisa dicoba dengan tombol Tambah dan Proses pembayaran (simulasi).

## Cara publikasi di GitHub Pages
1. Buat repository baru di GitHub bernama `tokoflow`.
2. Unggah `index.html` ke root repository (bukan hanya ZIP).
3. Buka Settings → Pages.
4. Pilih Deploy from a branch, branch `main`, folder `/(root)`, lalu Save.
5. Tunggu tautan Pages muncul. Formatnya `https://USERNAME.github.io/tokoflow/`.

## Catatan
Ini adalah prototipe front-end untuk presentasi. Data transaksi demo tidak disimpan ke database dan tombol pembayaran tidak memproses uang sungguhan. Untuk menjadi POS produksi, perlu backend, database, autentikasi, pengujian, dan integrasi pembayaran resmi.
